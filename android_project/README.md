# How to Build the Live Wallpaper APK

1.  **Download Video**: In the Web App, click **"Download Video Wallpaper"**. A file named `video.webm` will download.
2.  **Open Project**: Open this `android_project` folder in **Android Studio**.
3.  **Add Asset**: 
    -   Create a folder: `android_project/app/src/main/assets/`
    -   Move your downloaded `video.webm` into that folder.
4.  **Run**: Connect your Android phone and click **Run** (Green Play Button) in Android Studio.
5.  **Set Wallpaper**: The app will launch. Click **"Set Live Wallpaper"**.

*Note: Android Live Wallpapers require an installed APK (Application) to function. The web browser cannot install this directly for security reasons.*
